# Stillwave

Minimal audio player by Merelleyne Audio. Downloads are on the [releases page](https://github.com/merelleyneqt-sys/stillwave-releases/releases/latest).

- **Mac** (Apple Silicon, macOS 15+): the `.dmg`
- **Windows**: `x64.exe` for most PCs, `arm64.exe` for ARM PCs

The app updates itself.
